# EquineCare AI — AI კითხვა-პასუხის პროექტი

ეს პროექტი აერთიანებს ქართულ ჩატის გვერდს და Node.js სერვერს, რომელიც OpenAI API-ს უკავშირდება. ჩატი ინარჩუნებს მიმდინარე საუბრის კონტექსტს, სვამს დამატებით კითხვებს და სპეციალიზებულია ცხენების მოვლასა და ჯანმრთელობის უსაფრთხო საინფორმაციო მხარდაჭერაზე.

## მნიშვნელოვანი განსხვავება
მხოლოდ HTML ფაილი რეალურ AI-ს ვერ გაუშვებს. საჭიროა ეს პროექტი გაუშვა Node.js-ის მხარდაჭერიან სერვერზე და სერვერის გარემოს ცვლადებში დაამატო `OPENAI_API_KEY`. გასაღები არასოდეს ჩასვა HTML-ში, CodePen-ის frontend კოდში ან საჯარო GitHub რეპოზიტორიაში.

## გაშვება კომპიუტერზე
1. დააინსტალირე Node.js-ის მიმდინარე LTS ვერსია.
2. გახსენი ტერმინალი ამ საქაღალდეში.
3. გაუშვი `npm install`.
4. გარემოს ცვლადებში დაამატე `OPENAI_API_KEY` შენი API გასაღებით. სურვილისამებრ დააყენე `OPENAI_MODEL` იმ მოდელზე, რომელზეც შენს ანგარიშს წვდომა აქვს.
5. გაუშვი `npm start`.
6. ბრაუზერში გახსენი `http://localhost:3000`.

## ჰოსტინგი
ატვირთე პროექტი Node.js სერვისზე, რომელიც მხარს უჭერს გარემოს ცვლადებს. დაამატე `OPENAI_API_KEY` ჰოსტინგის საიდუმლო/Environment Variables განყოფილებაში და დააყენე start command `npm start`.

## CodePen
CodePen მხოლოდ frontend-ის დასატესტად გამოდგება; ამ პროექტის `/api/chat` endpoint-ისთვის ცალკე backend სერვერი აუცილებელია. CodePen-ის HTML ველში მარტო `index.html`-ის ჩასმა რეალურ AI-ს არ აამუშავებს.

## უსაფრთხოება
- არ გააზიარო API გასაღები.
- დაამატე ავტორიზაცია და rate limiting, თუ საიტი საჯაროდ გამოქვეყნდება; ამ საწყის ვერსიაში ისინი ჯერ არ არის ჩართული.
- AI პასუხი არ არის ვეტერინარული დიაგნოზი. გადაუდებელ შემთხვევებში დაუკავშირდი ვეტერინარს.
